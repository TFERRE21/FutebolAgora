## Regra de expansão

Modalidades, ligas, clubes e equipes devem ser entidades configuráveis. O código não deve depender de uma lista fixa de clubes.

## Conteúdo

O sistema deve produzir conteúdo editorial original baseado em fatos verificáveis. Não copiar ou republicar integralmente matérias de terceiros. Guardar fontes e timestamps para auditoria.
